- 실패가 있는 2건 처리를 마친 뒤 전체 진행률 100%를 검증
- 취소 시 취소 1건과 미처리 1건을 분리해 검증
- 자격 증명, 쿼리 토큰과 조각 식별자가 GUI 로그에 남지 않음을 검증

## 완료 기준

- 공개 YouTube 영상
- 접근 권한이 있는 로그인 필요 영상
- 직접 m3u8
- 지원되지 않는 URL과 DRM 콘텐츠
- 네트워크 중단, FFmpeg 누락, 중복 파일명
- 일괄 실패 격리와 재개

각 시나리오에 자동 테스트 또는 재현 가능한 수동 점검 절차가 있어야 한다.
